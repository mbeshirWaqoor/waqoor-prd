Three ways money moves.

Direct

Customer pays WAQOOR.

Subscriptions, plans and extra services. WAQOOR keeps it as its own revenue.

Marketplace

Customer pays WAQOOR, the ledger splits it, the merchant is settled.

Commission, fees, refunds and adjustments come off first. Merchant money is never mixed with WAQOOR revenue.

Cash on delivery

Customer pays the courier, the courier remits, the ledger settles.

Same commission and fees. Money counts only after the cash is confirmed collected.

The tech stack.

One monorepo

Next.js apps and the FastAPI backend in one repo, one CI. The TypeScript client is generated from the API schema.

Next.js storefronts

Server-rendered for search engines. Routes like /abc-group/fashion.

Next.js admin and POS

Every frontend is Next.js. POS is an installable web app; printers and scanners connect through the browser.

FastAPI API

One modular backend, one package per domain, async REST and OpenAPI. Background jobs on Celery.

PostgreSQL

Row-level security per company. Stock locks in the database. PostGIS for distance.

Search

PostgreSQL full-text search with trigram matching and Arabic normalization. No extra engine at launch.

AI gateway

Claude behind a model-neutral layer. Agents call the same API as everyone else.

Adapters

Payments and couriers plug in through interfaces. Jordan providers chosen after talks.

Infrastructure

Docker Compose, NGINX as the only reverse proxy, GitHub Actions and Sentry. A cloud region near Jordan.

Checkout, stock reservation and the ledger need strict transactions. Splitting them across services on day one would cost months of plumbing for no gain. Modules talk through interfaces and events, never each other's tables. Every row carries a company id. Money moves only through the ledger.

Decided, and still open.

Who pays for a subscription?

Decided: the company. One subscription per company. The plan sets how many shops it can publish. Creating a company stays free.

Is a product copied for every shop?

Decided: no, it is shared. A product is defined once per company. Each shop has its own listing with its own price, status and marketplace visibility.

Subscription or percentage?

Decided: both. A plan per company, a commission on marketplace orders, a low flat fee on storefront orders, and ads sold separately. The numbers are still open.

Which stack?

Decided: FastAPI and Next.js. FastAPI runs the API and background jobs (Celery). Next.js runs every frontend: storefronts, admin and POS. The API schema generates the frontend client so the two stay in sync.

Is cash on delivery supported?

Yes. For storefront and marketplace orders. New order states: awaiting delivery, cash collected, delivery failed or refused.

  • Who receives the cash from the courier: open
  • Remittance timing and failed-delivery fees: open
  • Order limits and phone confirmation: to confirm
What address does a shop get?

waqoor.com/company-name/shop-name, for example waqoor.com/abc-group/fashion. Every shop stays under the main domain.
